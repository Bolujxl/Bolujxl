# Boluwatife Lawal

Designer-engineer. I design products and build them myself.

I care about the small decisions that make a thing feel calm and intentional — the typographic choice that anchors a screen, the empty state that doesn't apologize, the audit that runs before the polish. My work pairs design taste with the engineering discipline to ship it.

---

### Selected work

**[receipts.me](https://receipts.me)** — a spending dashboard built around a single sentence.
Money is emotional. Most apps strip that out. This one keeps the calm and adds the clarity.
*React · Tailwind v4 · Recharts · TypeScript*

**[Mood Atlas](https://moodatlas.vercel.app)** — pick a mood, see a place.
An image-driven exploration of feeling and geography.
*React · Unsplash API · Vite*

**[Time-Locked Letters](https://the-timelockedapp.vercel.app)** — letters that arrive when they're meant to.
A quiet tool for writing to your future self.
*React · TypeScript · localStorage persistence*
